# Example Job Search Notes

This public file is fictional. Production candidate notes, CV material, and
search configuration belong in a private, commit-pinned configuration checkout.

The executable eligibility rules are the selected TOML file's `[search]`,
`[candidate]`, and `[policy]` tables. This prose is not evaluated as a rule set
and is not supplied to LLM prompts. Its contents participate only in the
re-evaluation fingerprint: changing this file may cause previously rejected
postings to be considered again.

For the fictional Avery Example profile, use the public
`job_search.example.toml` as the authoritative structured policy reference.
